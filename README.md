# Flippy-Bit
Based on [Q42](https://www.q42.nl/en)'s ['Flippy Bit And The Attack Of The Hexadecimals From Base 16'](https://flippybitandtheattackofthehexadecimalsfrombase16.com/), made with Typescript, HTML, and CSS!

## Usage

Setup (requires node.js):

```bash
> npm install
> npm run dev
```

## Controls

- Each digit in the array can be controlled with your keyboard, using
  the keys from 1-8 respectively
- Each digit can also be toggled with your mouse by clicking on a digit with a pointer icon
- The game can be restarted at any point by pressing the 'r' key

## AI Declaration & References
